# SMS - Stitch UI Prototypes & Messaging Interface

Protótipos de interface e telas de mensagens e perfis desenvolvidos com Stitch.

## Estrutura do Projeto

- `stitch_mostrar_pro_lucas/`: Telas e protótipos de interface, feeds, menus e configurações.
  - Carteira digital e documentos
  - Configuração de loja e horários flexíveis
  - Feed principal e unificado (pessoal/comercial)
  - Perfis e canais de conversa
  - Guias locais e mapas
  - Status e menus laterais
